# 🍅 بوت بومودورو الدراسي - ديسكورد

بوت ديسكورد متكامل لإدارة جلسات بومودورو الجماعية، مع نظام السلاسل اليومية والأوسمة، وتكامل مع القنوات الصوتية.

## ✨ المميزات

### 1. جلسات بومودورو الجماعية (Group Pomodoro / Study Rooms)
- إنشاء جلسات تركيز جماعية عبر الأمر `/pomodoro start`
- انضمام عدة أعضاء لنفس الجلسة عبر `/pomodoro join` أو زر الانضمام
- إرسال منشن للجميع عند انتهاء وقت التركيز أو بداية الاستراحة
- عرض حالة الجلسة والوقت المتبقي عبر `/pomodoro status`
- إلغاء الجلسة عبر `/pomodoro cancel` (للمشرفين أو المنشئ)

### 2. تكامل القنوات الصوتية (Voice Focus Integration)
- عند مشاركة العضو في جلسة بومودورو، يتم منحه رتبة مؤقتة `@🍅 Focused`
- تغيير اسم العضو مؤقتاً بإضافة رمز 🍅 لتنبيه الآخرين بعدم إزعاجه
- إزالة الرتبة والاسم عند انتهاء الجلسة

### 3. السلاسل اليومية والأوسمة (Daily Streaks & Badges)
- نظام 슬سله (Streak): احتساب الأيام المتتالية التي أكمل فيها المستخدم جلسة تركيز واحدة على الأقل
- أوسمة تلقائية بناءً على إجمالي ساعات التركيز:
  - 🌱 مبتدئ تركيز (0+ ساعة)
  - 📚 متركز ممارس (10+ ساعات)
  - 🍅 محترف تركيز (25+ ساعة)
  - 🏆 خبير انضباط (50+ ساعة)
  - 👑 أسطورة الانضباط (100+ ساعة)
  - 👑⚡ إمبراطور التركيز (200+ ساعة)

### 4. إحصائيات الخادم (Server Stats)
- عرض إحصائيات إجمالية للخادم عبر `/pomodoro stats`
- إجمالي المستخدمين، ساعات التركيز، الجلسات، أعلى سلسلة يومية، إلخ.

## 🚀 التثبيت والتشغيل

### المتطلبات
- Node.js v18 이상
- حساب ديسكورد مع بوت مفعل

### خطوات التثبيت

1. **استنساخ المشروع أو تحميل الملفات**

2. **تثبيت الاعتمادات:**
   ```bash
   npm install
   ```

3. **إعداد ملف البيئة:**
   انسخ ملف `.env.example` إلى `.env` وعدل القيم:
   ```bash
   copy .env.example .env
   ```
   ثم افتح `.env` وأضف توكن البوت الخاص بك:
   ```
   DISCORD_TOKEN=your_bot_token_here
   ```

4. **إنشاء بوت في بوابة ديسكورد للمطورين:**
   - اذهب إلى [Discord Developer Portal](https://discord.com/developers/applications)
   - أنشئ تطبيق جديد (New Application)
   - اذهب إلى قسم **Bot** وقم بتفعيل البوت
   - فعال الصلاحيات التالية (Privileged Gateway Intents):
     - ✅ Presence Intent
     - ✅ Server Members Intent
     - ✅ Message Content Intent
   - انسخ التوكن وضعه في ملف `.env`

5. **دعوة البوت إلى خادمك:**
   في بوابة المطورين، اذهب إلى **OAuth2 → URL Generator** واختر النطاقات التالية:
   - `bot`
   - `applications.commands`
   
   واختر الصلاحيات:
   - `Send Messages`
   - `Manage Roles`
   - `Manage Nicknames`
   - `Read Message History`
   - `Connect` و `Speak` (للقنوات الصوتية)

6. **تشغيل البوت:**
   ```bash
   npm start
   ```

## 📋 قائمة الأوامر

| الأمر | الوصف |
|-------|-------|
| `/pomodoro start` | بدء جلسة بومودورو جديدة (يمكن تحديد مدة التركيز والاستراحة) |
| `/pomodoro join` | الانضمام إلى جلسة نشطة في القناة الحالية |
| `/pomodoro leave` | مغادرة الجلسة الحالية |
| `/pomodoro status` | عرض حالة الجلسة والوقت المتبقي |
| `/pomodoro cancel` | إلغاء الجلسة (للمشرفين أو المنشئ) |
| `/pomodoro profile [عضو]` | عرض ملف التركيز والسلسلة اليومية |
| `/pomodoro stats` | عرض إحصائيات الخادم الإجمالية |
| `/pomodoro settings` | تعديل إعدادات الجلسات (للمشرفين فقط) |

## ⚠️ ملاحظات هامة

1. **البيانات:** يتم حفظ البيانات في ملفات JSON داخل مجلد `data/` لكل خادم على حدة.
2. **الصلاحيات:** تأكد من إعطاء البوت صلاحية `Manage Roles` و `Manage Nicknames` لتعمل ميزة رتبة التركيز وتغيير الأسماء.
3. **الأوامر slash:** قد تستغرق الأوامر حتى ساعة للظهور في ديسكورد بعد النشر الأولي. للتسجيل الفوري، أضف `GUILD_ID` في ملف `.env`.
4. **إعادة التشغيل:** عند إعادة تشغيل البوت، يتم استعادة الجلسات النشطة وتوقيتاتها.

## 🛠️ التطوير المستقبلي

يمكن إضافة الميزات التالية في الإصدارات القادمة:

- إشعارات خاصة (DM) عند انتهاء الجلسات
- نظام لوحات المتصدرين (Leaderboard)
- تكامل مع تقويم جوجل
